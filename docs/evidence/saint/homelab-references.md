## Existing platform

The current architecture documents one Ubuntu Server LTS host using Docker Swarm, Doco-CD, GitHub and a private Distribution Registry. The host is a six-core mini-PC with 16 GB RAM. Existing workload limits are not evidence of spare resources: the remote-development service allows 8 GB and Ignis allows 4 GB. Current utilization and the project's safe resource budget still require an authorized preflight. [Architecture](https://github.com/azther0z-homelab/homelab-architecture/blob/e1f8c88a09793d1474d03d41d56647946004e1bf/wiki/architecture/architecture.md), [server context](https://github.com/azther0z-homelab/homelab-architecture/blob/e1f8c88a09793d1474d03d41d56647946004e1bf/wiki/architecture/server-architecture-context.md), [remote-dev manifest](https://github.com/azther0z-homelab/homelab-gitops/blob/841efb4a3c312326ceb2856dc4532433982b4879/apps/remote-dev/compose.yaml), [Ignis manifest](https://github.com/azther0z-homelab/homelab-gitops/blob/841efb4a3c312326ceb2856dc4532433982b4879/apps/ignis/compose.yaml).

Doco-CD v0.129.0 polls the GitOps repository every minute and discovers immediate application directories under `apps/`. The same reconciler also polls the existing Tutor Matcher monolith repository. Application state is defined by Swarm-compatible `apps/<project>/compose.yaml`. The existing reconciler and its poll configuration should be reused. [Root discovery settings](https://github.com/azther0z-homelab/homelab-gitops/blob/841efb4a3c312326ceb2856dc4532433982b4879/.doco-cd.yaml), [main reconciler](https://github.com/azther0z-homelab/homelab-gitops/blob/841efb4a3c312326ceb2856dc4532433982b4879/doco-main/compose.yaml).

SOPS/age runtime configuration and private registry pull authorization are already part of the platform. Trusted owned repositories build through the approved host runner and rootless BuildKit. Custom-image promotion changes only a service's image field to its immutable digest; the existing reusable workflow pushes that change to GitOps main. Running promotion can therefore cause deployment and requires separate release authorization. This project repository's eligibility for that trusted runner is not established merely by reading the platform docs. [GitOps contract](https://github.com/azther0z-homelab/homelab-architecture/blob/e1f8c88a09793d1474d03d41d56647946004e1bf/wiki/spec/gitops-deployment.md), [promotion procedure](https://github.com/azther0z-homelab/homelab-gitops/blob/841efb4a3c312326ceb2856dc4532433982b4879/docs/custom-image-promotion.md).

## Existing browser ingress

The active design uses a host-level cloudflared daemon, with Cloudflare DNS/tunnel/Access configuration managed in the GitOps Terraform root. It does not require a new Tailscale-only entry, public Caddy installation or shared proxy overlay for this application. DNS/tunnel routing and Cloudflare Access policies are separate concerns. [Architecture](https://github.com/azther0z-homelab/homelab-architecture/blob/e1f8c88a09793d1474d03d41d56647946004e1bf/wiki/architecture/architecture.md), [tunnel routes](https://github.com/azther0z-homelab/homelab-gitops/blob/841efb4a3c312326ceb2856dc4532433982b4879/infrastructure/cloudflare/tunnel.tf), [DNS](https://github.com/azther0z-homelab/homelab-gitops/blob/841efb4a3c312326ceb2856dc4532433982b4879/infrastructure/cloudflare/dns.tf), [Access applications](https://github.com/azther0z-homelab/homelab-gitops/blob/841efb4a3c312326ceb2856dc4532433982b4879/infrastructure/cloudflare/access.tf).

The existing Tutor Matcher hostname forwards to host port 3333. Preserve it during independent microservice implementation. The local review template proposes a separate app directory, hostname and candidate origin port 3334; those are proposed additions, not deployed resources or evidence that the port is free. Backend service, database, RabbitMQ, Traefik admin and Docker API proxy ports stay private; this stack does not use Consul. Host-mode publication of the web origin requires checking the actual Docker-aware IPv4/IPv6 firewall before routing traffic to it.

## Remaining release checks

Verify host capacity, approved runner access, the storage-owning node placement, candidate hostname/port availability, intended instructor/demo audience, encrypted configuration and all owner images. Review the GitOps bundle and Terraform change before requesting publication, promotion or server authorization. Do not overwrite the monolith route, bootstrap a second Doco-CD instance, move existing persistent storage, or treat the historical shopping wiki as the current platform.
