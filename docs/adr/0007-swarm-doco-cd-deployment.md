# Hosted Swarm deployment with Doco-CD

Retain Docker Swarm and Doco-CD for the hosted course demo. Doco-CD deploys the repository's hosted manifest from reviewed configuration. Keep local Docker Compose as the fallback.

This preserves the selected direction without introducing a Kubernetes migration before 10 November. Kubernetes is not required by the supplied syllabus and is not selected for this delivery. Actual server changes and deployment remain separate work.

Source: [Tutor Matcher PDF](../sources/tutor-matcher.pdf), pp. 12, original ADR-007. Reconciled against the [accepted requirements](../requirements.md) on 6 November 2026.
