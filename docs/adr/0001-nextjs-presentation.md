# Next.js for presentation and routing

Keep Next.js responsible for pages, navigation, and rendering. Backend APIs own business rules and data access, so interface changes do not duplicate booking or wallet policy.

This remains a delivery constraint. The current checkout has no frontend, so acceptance does not establish implementation completion.

Source: [Tutor Matcher PDF](../sources/tutor-matcher.pdf), pp. 10, original ADR-001. Reconciled against the [accepted requirements](../requirements.md) on 6 November 2026.
